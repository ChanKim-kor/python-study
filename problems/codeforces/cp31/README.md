## Status legend

| Mark | Meaning |
|---|---|
| ⬜ | Not attempted |

## Practice rule

1. Try independently first.  
2. Record **Time** and **Attempts** after the session.  
3. If stuck, use hints progressively rather than jumping straight to the solution.  
4. Mark reusable ideas or mistakes briefly in **Review**.  
5. Revisit `🔁` / `📖` problems before moving too far ahead.
